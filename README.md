# 最近1年で自分で調べて試したIT関連のこと

## 1. 生成AIを使った自作ゲームエンジン開発

### きっかけ

夏休み中、前期に学んだレンダリングエンジンづくりの振り返りとプロジェクトの整理をしていた際、ふと「今のAIと一緒なら、レンダリングだけでなくゲームエンジンまで作れるのでは」と思い、制作を開始しました。9月から開始し、現在まで継続中です。

### どこまで試したか

* 自分は**設計・要件定義などの上流工程**を担当し、**実装は生成AIに任せる**という役割分担で開発しています。
* 生成されたコードは自分でレビューし、動作確認をしながら修正を指示しています。
* 開発の過程は、note で「ゲームエンジン開発記」として連載しています（HalCa名義）。
  * https://note.com/halca_6415

### 効果

* 自分一人では時間がかかる実装部分をAIに任せることで、**設計や仕様を考えることに時間を使えるようになりました**。
* 「何を作りたいか」を言葉で正確に伝える必要があるため、**要件を整理する力が身につきました**。

## 2. 生成AIを「答え合わせ役」にした学習

### きっかけ

AIに任せるだけでは中身を理解しないままになってしまうと感じ、以下の工夫をするようにしました。

### どこまで試したか

次の手順で学習しました。

1. まず自分で構造や関数の流れを仮説として書きます。
2. 生成AIが出したコードと答え合わせをします。
3. 写経して理解を深めます。
4. 最後に、何も見ずに白紙から再現します。

### 効果

* 分からない箇所をその場でAIに質問できるため、**調べ物の時間を短縮できました**。
* デバッグでも、原因の候補をAIと一緒に絞り込むことで**手戻りが減りました**。
* 基盤コードを一度自分の手で通したことで、エンジン開発でAIのコードをレビューする際にも、**どこが怪しいかを判断できるようになりました**。

## 3. 生成AIで自分用の作業ツールを作る

### きっかけ

制作の中で「この作業が面倒」「ちょうどいいツールがない」と感じたときに、既存のツールを探すだけでなく、生成AIに頼んで自分専用のツールを作ってしまうことを試しました。

### どこまで試したか

* **リズムゲームの譜面制作ツール**
  * 自作リズムゲームの譜面を作るためのツールを、生成AIに作ってもらいました。
  * 曲を再生しながらノーツを配置でき、実際にノーツが鳴るタイミングを耳で確認しながら作業できます。
  * 小節の追加・削除、既存の譜面ファイルの読み込みと編集、JSON形式での書き出しに対応しています。
* **動画をGIFに変換するWebツール**
  * note の記事に載せるGIFを作るため、生成AIに作ってもらい、完成させました。

### 効果

* 以前は譜面をコードに直接書き込んで（ハードコーディングして）いたため、タイミングの調整のたびにコードを書き換えて確認する必要がありました。ツールを作ったことで、**曲を聴きながら直感的に譜面を作れるようになり、作業が大幅に楽になりました**。
* 譜面をJSONファイルとして書き出せるようになったため、**コードを触らずに譜面を追加・修正できるようになりました**。
* GIF変換ツールが完成したことで、note の記事に載せるGIFを**ブラウザ上ですぐに作れるようになりました**。
* 「ツールがなければ作る」という選択肢が増えたことで、**面倒な作業を自分で解消できるようになりました**。
